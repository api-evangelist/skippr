# Skippr

> Skippr builds "The Live AI Employee" — real-time AI agents that see, talk, and operate software. Embeddable voice agents demonstrate products, onboard users, join customer video calls, and complete software tasks autonomously. Skippr also ships a browser extension that runs AI product reviews (PM, designer, content, accessibility) and an MCP server that feeds those findings to AI coding agents. Backed by Bessemer Venture Partners. SOC 2 Type II and ISO 27001 certified.

## Products
- [Skippr Live AI Employee](https://skippr.ai/): Embeddable real-time voice/vision agent for onboarding, demos, and task automation.
- [Skippr Browser Extension](https://chrome.google.com/webstore/detail/dmbmdnppaoabphpkafbkdcbinkfnjpmh): AI product review — flags UX, accessibility, and product-quality issues.

## Developer
- [Live Agent SDK (npm @skippr/live-agent-sdk)](https://www.npmjs.com/package/@skippr/live-agent-sdk): Drop the script into your app and initialize with your keys.
- [Extension MCP Server (npm @skippr/extension-mcp-server)](https://www.npmjs.com/package/@skippr/extension-mcp-server): MCP server bridging Skippr product-review issues into AI coding agents; install `npx -y @skippr/extension-mcp-server`.
